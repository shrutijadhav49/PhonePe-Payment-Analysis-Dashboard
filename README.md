# PhonePe-Payment-Analysis-Dashboard
The dashboard provides a comprehensive view of transaction performance, customer behaviour, payment success, and service level trends. where I transformed payment transaction data into an interactive dashboard design to support data-driven decision-making.


🔍Project Focus:
The dashboard provides a comprehensive view of transaction performance, customer behaviour, payment success, and service level trends.

💡 Key Metrices:
• 300k+ total transactions 
•108k unique users 
• ₹3.47B total transaction value
• 96% successful transaction rate 

📈 Implementation:
• Cleaned and transformed raw data into power query.
• Developed calculated measures and KPIs using Dax.
• Design interactive KPI cards and visualizations.
• Added dynamic filters for Months and Payment Status.
• Analyzed transaction trends across age groups, services, users, and weekday/ weekend.

⚙️key insights:
The dashboard helps to identify high value services, customer segments, transaction performance over time, and areas requiring investigation such as unsuccessful or pending payments.
This project strengthened my practical skills in power bi, DAX, data cleaning, business analystics, with a focus on turning raw data into meaningful insights.

This dashboard transforms complex transaction data into an interactive and easy-to-understand visual story, covering:
🔹 Transaction trends & total value
🔹 User & payment success analysis
🔹 Age segment contribution
🔹 Service-wise transaction value
🔹 Top users by transaction value
🔹 Weekday vs. weekend usage
This project helped me strengthen my skills in data visualization, dashboard design, and business analytics while focusing on turning data into meaningful insights.
